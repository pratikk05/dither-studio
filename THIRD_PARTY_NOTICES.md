## Dithering Shader reference

Reference project: https://github.com/niccolofanton/dithering-shader
Author: Niccolò Fanton
License: MIT

The project README describes its implementation as a real-time ordered (Bayer) dithering post-processing effect for React Three Fiber. The original project credits the original dithering pattern to Klems on Shadertoy. This application uses the same general ordered Bayer dithering technique and provides its own implementation and interface.
